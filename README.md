# 📊 **Pesquisa de Satisfação do Cliente | Python.**


## 🔎 Sobre o projeto:

Este projeto consiste no desenvolvimento de um programa em **Python** para a empresa fictícia TudoWeb, com o objetivo de realizar uma pesquisa de satisfação sobre a qualidade do atendimento prestado aos clientes.

O sistema coleta informações de 50 entrevistados, registra suas opiniões e ao final contabiliza a quantidade de avaliações classificadas como EXCELENTE e RUIM.

A partir dos resultados, a empresa poderá melhorar a experiência de seus clientes tomando decisões estratégicas mais assertivas.

## ⚙️ Funcionamento do Programa:

O programa solicita três informações de cada entrevistado:

- Nome;
- Idade;
- Número correspondente à sua avaliação, seguindo os seguintes parâmetros:
  
| Número | Opinião |
|:---:|:---|
| 1 | EXCELENTE |
| 2 | BOM |
| 3 | RUIM |


### **Exemplo de Funcionamento:**

```
Pesquisa de Satisfação TudoWeb.
Sua opinião importa! Responda à pesquisa sobre o nosso atendimento.

Entrevistado 1
Digite seu nome: Julia
Digite sua idade: 22

1- EXCELENTE | 2- BOM | 3- RUIM
Insira o número que corresponde à sua opinião: 1
Opinião registrada!
```

**...**

```
Quantidade de entrevistados que avaliaram como EXCELENTE: x
Quantidade de entrevistados que avaliaram como RUIM: x
```


## ▶️ Como Executar o Projeto:

### Pré-requisitos:

- Ter o Python instalado;
- Ter o Visual Studio Code ou outro editor de código;
- Ter o arquivo pesquisa.py disponível no computador;
  
#### Passo a passo:

1. Clone o repositório:
```
git clone https://github.com/juliafunes/pesquisa-opiniao
```

2. Acesse a pasta do projeto:
```
cd pesquisa-opiniao
```

3. Execute o programa:
```
python pesquisa.py
```

1. Responda às perguntas informando o nome, a idade e a opinião de cada entrevistado.

Ao final, o programa exibirá o resumo das avaliações.
